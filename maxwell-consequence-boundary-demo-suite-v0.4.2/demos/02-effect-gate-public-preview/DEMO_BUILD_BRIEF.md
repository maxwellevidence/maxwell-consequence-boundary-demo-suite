# Demo Build Brief — Demo 02

## Demo name

Maxwell Effect Gate Public Preview v0.3.0

## Suite position

Demo 02 in the Maxwell Consequence Boundary Demo Suite.

Demo 01 gives the simple evidence-before-effect entry point. Demo 02 gives the
deeper technical-review artifact with public policy, OIDC authority-context
examples, manifest verification, adversarial tests, and bounded claims.

## Primary invariant

```text
No policy-derived allow -> no effect_record.json.
```

## Public-safe story

A fictional AI-assisted incident-remediation workflow proposes downstream
change-control records. Maxwell captures public evidence and authority context,
evaluates a public policy, writes a decision receipt, and creates downstream
effect only when the policy permits it.

## Intended audience

- Developers
- Technical reviewers
- Diligence reviewers
- AI governance teams
- Security and compliance reviewers

## Do not add

- Real customer data
- Real production keys
- Real vulnerability remediation instructions
- Internal Maxwell evaluator chains
- Private authority thresholds
- Live IAM credentials
- Claims of production readiness, certification, or third-party validation
