# Public Preview Boundaries

This package is intentionally small and public-safe.

It demonstrates:

- synthetic proposed action inputs,
- local evidence bundle construction,
- local authority-context normalization,
- local YAML policy evaluation,
- decision receipts,
- effect-record creation only when permitted,
- no-effect markers when not permitted,
- and manifest-bound verification.

It does not demonstrate or disclose:

- production Maxwell Evidence infrastructure,
- private Golden Tree internals,
- private MEVIDA or MESI implementation details,
- real identity-provider integration,
- real downstream execution,
- real customer workflows,
- or regulated production controls.
