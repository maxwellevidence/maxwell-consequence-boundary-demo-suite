# Demo Build Brief

## Demo

Maxwell Effect Gate Basic Demo v0.1.0

## Position in suite

Demo 01 of the Maxwell Consequence Boundary Demo Suite.

## Purpose

Give reviewers the simplest runnable proof of evidence-before-effect control before they move to deeper demos such as technical public preview, rogue-agent payment, multi-agent authority, incident reconstruction, policy replay, sensitive data access, human review, prompt-injection boundary, and public-sector determination.

## Core invariant

No sufficient evidence + authority -> no downstream effect record.

## Public-safe design

The demo uses synthetic JSON inputs, a local YAML policy, deterministic local artifact generation, manifest-bound verification, and no real downstream actions.
