# Claims and Limitations

## What this demo claims

- A task handoff alone is not treated as downstream authority.
- Delegated authority must match the requested scope and target system.
- Evidence continuity must survive the handoff.
- Non-permitted cases do not create `delegated_effect_record.json`.
- Run artifacts are manifest-bound and tamper-detectable in this local demo.

## What this demo does not claim

- It is not a production authorization system.
- It is not legal, compliance, or audit advice.
- It is not a complete agent orchestration framework.
- It is not the full Maxwell architecture.
- It does not connect to real identity providers, ticketing systems, or production APIs.


## v0.4.0 adversarial harness boundary

The adversarial harness is an internal public-preview exercise over synthetic local inputs. It is not an independent third-party red-team validation and is not a production-security certification.
