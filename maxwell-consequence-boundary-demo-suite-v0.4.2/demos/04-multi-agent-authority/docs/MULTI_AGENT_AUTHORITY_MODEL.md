# Multi-Agent Authority Model

This demo separates three concepts that are often conflated in agentic systems.

## Task handoff

One agent asks another agent to perform work.

## Authority handoff

The receiving agent is granted a bounded authority to create a downstream effect.

## Evidence continuity

The evidence packet supporting the action remains bound to the handoff and can be
reconstructed later.

The demo only commits a delegated downstream effect when all three are present
and aligned with the requested target scope and target system.
