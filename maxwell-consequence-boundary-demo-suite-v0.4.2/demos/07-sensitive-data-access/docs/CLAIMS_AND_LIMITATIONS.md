# Claims and Limitations

## What this demo claims

This demo claims that, within this synthetic local proof surface:

- Proposed AI data retrieval is evaluated before downstream effect.
- A data-access effect record is created only when policy-derived evidence and authority checks permit it.
- Review and suppression outcomes still produce reconstructable receipts.
- Prompt-injected instructions do not override the evaluated data-access policy.
- Verification can detect tampering with manifest-covered artifacts.

## What this demo does not claim

This demo is not:

- A production access-control system.
- Legal advice.
- A privacy-impact assessment.
- A compliance certification.
- A full Maxwell Evidence architecture disclosure.
- A guarantee that every privacy, regulatory, or security requirement is represented.
- A system that connects to or returns real sensitive data.

## Public-safe boundary

The package demonstrates behavior and artifact shape, not private Maxwell internals.


## v0.4.0 adversarial harness boundary

The adversarial harness is an internal public-preview exercise over synthetic local inputs. It is not an independent third-party red-team validation and is not a production-security certification.
