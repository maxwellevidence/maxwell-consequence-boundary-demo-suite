# Demo Build Brief

## Demo name

Maxwell Prompt Injection Boundary Demo

## Suite position

Demo 09 of the Maxwell Consequence Boundary Demo Suite.

## Hook

Even if the model says "approve," downstream effect still requires evidence and authority.

## Core invariant

```text
No valid evidence + authority + trusted instruction boundary -> no downstream effect record.
```

## What makes it attention-grabbing

Prompt injection is a familiar AI risk. This demo reframes the issue at the consequence boundary. The demo does not claim the prompt cannot influence the model. It shows that model output alone cannot authorize enterprise effect.

## Public-safe design

- Synthetic cases only.
- No external systems.
- No real secrets.
- No real customer or employee data.
- No production prompt-injection detector claim.
- No complete Maxwell architecture disclosure.
