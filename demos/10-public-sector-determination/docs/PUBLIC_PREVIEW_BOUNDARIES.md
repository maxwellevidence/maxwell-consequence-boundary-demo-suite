# Public Preview Boundaries

This package is a public-safe proof surface. It demonstrates consequence-boundary behavior without exposing private Maxwell implementation details.

## Included

- Synthetic case records.
- Simplified public-sector policy rules.
- Deterministic local evaluation.
- Reviewable JSON artifacts.
- Tests for the public invariant.

## Not included

- Real public-benefit eligibility rules.
- Real applicant data.
- Integration with public systems.
- Production security architecture.
- Legal or compliance advice.
