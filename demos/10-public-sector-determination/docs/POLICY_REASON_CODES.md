# Policy Reason Codes

| Reason code | Meaning |
|---|---|
| `PUBLIC_SECTOR_DETERMINATION_EFFECT_COMMITTED` | The determination effect was permitted. |
| `REQUIRED_ELIGIBILITY_EVIDENCE_MISSING` | Required eligibility or program evidence is missing. |
| `CASE_RECORD_INCONSISTENT_REQUIRES_REVIEW` | The case record is inconsistent and requires review. |
| `UNAUTHORIZED_AUTOMATED_ADVERSE_DETERMINATION` | AI or automation attempted to bind an adverse determination. |
| `DUE_PROCESS_REVIEW_REQUIRED` | Authorized review is required before effect. |
| `NOTICE_AND_APPEAL_RIGHTS_MISSING` | Required notice or appeal-rights evidence is missing. |
| `MISSING_CASE_AUTHORITY` | The actor lacks recognized determination authority. |
| `PROGRAM_OR_JURISDICTION_SCOPE_VIOLATION` | The program or jurisdiction is outside authority scope. |
| `DETERMINATION_TYPE_SCOPE_VIOLATION` | The determination type is outside authority scope. |
| `UNSAFE_INSTRUCTION_PRESERVED_NOT_AUTHORITY` | Unsafe instruction text was preserved as evidence, not treated as authority. |
