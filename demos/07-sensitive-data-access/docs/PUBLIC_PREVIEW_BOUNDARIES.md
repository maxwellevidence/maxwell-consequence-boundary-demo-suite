# Public Preview Boundaries

This demo is intentionally limited.

It does not include:

- Real sensitive data.
- Real customer data.
- Real employee data.
- Protected health information.
- Production connectors.
- External identity providers.
- Full Maxwell architecture internals.

It does include enough behavior to demonstrate the public invariant:

```text
No valid role + purpose + data scope + evidence -> no data access effect record.
```
