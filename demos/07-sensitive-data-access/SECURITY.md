# Security

This public-preview demo is synthetic and local-only.

Please do not submit real customer data, employee data, protected health information, secrets,
API keys, access tokens, or internal production policies in issues, pull requests, screenshots,
or demo runs.

If you believe you found a security concern in this public demo package, contact:

`oswaldo@maxwellevidence.com`

This demo intentionally does not connect to a real database or return real sensitive data. The
`data_access_effect_record.json` artifact records that access would be permitted under the demo
policy; it does not contain the underlying data payload.
