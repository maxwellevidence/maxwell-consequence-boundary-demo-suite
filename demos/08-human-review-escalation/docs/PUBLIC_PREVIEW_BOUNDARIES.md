# Public Preview Boundaries

This demo is designed to show public behavior without exposing private Maxwell architecture.

It intentionally does not include:

- production identity integration,
- production workflow integration,
- real customer data,
- real approvals,
- real downstream system calls,
- private Maxwell runtime or evidence-plane internals.

The useful proof surface is the artifact behavior: proposed action, review evidence, reviewer authority, final decision receipt, effect record or no-effect marker, manifest, and verification report.
