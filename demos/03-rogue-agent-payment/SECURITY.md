# Security

This public demo contains only synthetic examples and local deterministic policy logic.

Please do not submit real customer data, vendor data, employee data, invoices, bank details, credentials, access tokens, or payment files when testing this demo.

Report security concerns to: oswaldo@maxwellevidence.com

## Intentional limitations

This demo is not a payment processor, workflow engine, bank integration, fraud-detection product, or production authorization layer. It is a public-safe proof surface for evidence-before-effect control.
