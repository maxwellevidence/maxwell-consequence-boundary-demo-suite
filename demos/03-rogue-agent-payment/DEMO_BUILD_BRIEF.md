# Demo Build Brief

## Demo

Maxwell Rogue Agent Payment Demo v0.1.0

## Suite position

Demo 03 in the Maxwell Consequence Boundary Demo Suite.

## Audience

Finance leaders, enterprise operations, payment-control teams, procurement teams, audit, fraud-risk teams, and AI governance reviewers.

## Attention hook

A rogue or over-eager AI finance assistant may recommend payment, but recommendation is not authority.

## Public invariant

No sufficient payment evidence + approval authority -> no downstream payment effect record.

## Public-safe implementation

This demo uses only synthetic data, local deterministic policy logic, and local JSON artifacts.

No real payment is initiated or connected to a downstream financial system.
