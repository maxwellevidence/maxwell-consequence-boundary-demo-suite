# Public Preview Boundaries

This demo intentionally exposes only a simplified public-safe payment-control proof surface.

It does not include:

- production Maxwell Evidence internals,
- live integrations,
- real payment rails,
- real vendor master data,
- real bank-account validation,
- real customer data,
- live identity systems,
- or private enterprise policies.

It does include enough behavior to evaluate the public invariant:

> No sufficient payment evidence + authority -> no downstream payment effect record.
