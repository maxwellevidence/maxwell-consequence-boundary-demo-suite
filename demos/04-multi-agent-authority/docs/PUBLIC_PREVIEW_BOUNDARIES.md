# Public Preview Boundaries

This package is designed to be useful for public review without exposing private
implementation details.

Included:

- Synthetic agent identities.
- Simple local policy rules.
- Inspectable evidence and authority artifacts.
- Tests and verification routines.

Excluded:

- Real enterprise identity integrations.
- Production agent runtime implementation.
- Private Maxwell evidence-plane or governance-plane internals.
- Real customer, employee, incident, or financial data.
