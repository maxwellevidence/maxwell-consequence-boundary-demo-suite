# GitHub Publishing Checklist

Before publishing:

- [ ] Run `make clean`.
- [ ] Run `make demo`.
- [ ] Run `make verify`.
- [ ] Run `make test`.
- [ ] Run `make package-check`.
- [ ] Confirm no generated `artifacts/runs/` directory is committed.
- [ ] Confirm `artifacts/sample_outputs/` is intentional.
- [ ] Confirm no real credentials or private data are present.
- [ ] Confirm README and claims boundaries match the public positioning.
